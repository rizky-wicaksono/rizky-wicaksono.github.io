How to make an audio file smaller: interviews, podcasts and voice notes

Draft by AI · Reviewed by Rizky Wicaksono · 25 November 2026 · 5 min read

In short

An audio file’s size is its bitrate multiplied by its length. For speech, AAC audio in an M4A file at 64 kbps is clear and small: one hour is about 29 MB, so a 30-minute interview is about 14 MB and fits in an email. Use mono for a single microphone. Music needs more, around 128 kbps.

How big is an audio file?

Size is bitrate (kilobits per second) times length. Uncompressed CD-quality audio, such as a WAV file from a recorder, uses 1,411 kbps: 44,100 samples a second, 16 bits each, two channels. That is about 10.6 MB per minute, or more than 600 MB for an hour-long interview.

Compressed audio is far smaller. Here is how much space AAC audio takes at common bitrates:

  • 48 kbps: about 0.36 MB a minute, 22 MB an hour (speech only)
  • 64 kbps: about 0.48 MB a minute, 29 MB an hour (clear speech, podcasts)
  • 96 kbps: about 0.72 MB a minute, 43 MB an hour (good speech, fair music)
  • 128 kbps: about 0.96 MB a minute, 58 MB an hour (music)

Which settings should I use for speech?

  • Bitrate: 64 kbps for interviews, podcasts and voice memos. Go down to 48 kbps only if size matters more than sound.
  • Channels: mono. One voice on one microphone does not need two channels, and mono gives the bitrate to a single channel.
  • Sample rate: keep it as is, or choose 22 kHz for speech. Lower rates cut high frequencies, which voices barely use.

To hit an exact size, choose Target file size instead and type a number, such as 18 MB for email. The tool picks the bitrate that lands close to it.

How PR teams use this

  • Interview recordings for journalists. After a media interview, send the reporter a compressed copy so they can check quotes. A 30-minute talk at 64 kbps mono is about 14 MB.
  • Spokesperson voice notes and radio grabs. Short clips at 64 to 96 kbps send fast on WhatsApp and email.
  • Podcast guest files. Share a light listening copy for review, and keep the original for the edit.
  • Audio from a video. Drop in the event video to get just the speech as a small M4A, useful for transcription.

Always keep the original recording. Compression removes detail that cannot be brought back, so edit from the original and send the small copy.

Why M4A, and is my recording uploaded?

M4A is AAC audio in an MP4 file. It plays on iPhone, Android, Windows and Mac without extra apps. The tool encodes with the AAC encoder built into your browser, so the recording is never uploaded, which matters for off-the-record or embargoed interviews.

Frequently asked questions

What bitrate is good for a voice recording?

64 kbps mono is clear for speech and keeps an hour to about 29 MB. Use 96 kbps if the recording has music or several voices you want to keep crisp.

Is M4A smaller than MP3?

At the same bitrate, the file size is the same, because size is bitrate times length. What differs is the codec: M4A uses AAC. Choose the bitrate first.

How do I make a WAV file smaller?

Convert it to M4A. A WAV at CD quality uses 1,411 kbps; the same recording at 64 kbps is about 22 times smaller.

Can I send an M4A file on WhatsApp?

Yes. You can send it as a document, which WhatsApp allows up to 2 GB, though a smaller file is quicker for the recipient to download.

Can I get the audio out of a video?

Yes. Drop the video into the M4A Compressor; only the sound is kept and saved as an M4A file.
